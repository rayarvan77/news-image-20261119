## The image

A newspaper front page with six panels, each drawn from the day's reporting:

1. **Vice City opens** — Grand Theft Auto VI begins its global rollout,
   ending a 13-year wait; gamers flood back to Vice City amid enormous hype.
2. **Three powers, one table** — Trump, Xi and Putin hold trilateral talks
   at the APEC summit in Shenzhen.
3. **Gulf exchanges fire** — the U.S. strikes a missile site on Iran's
   Qeshm Island; Iran hits a U.S. radar facility in Bahrain, then widens
   attacks to a U.S. base in Kuwait.
4. **Jeffries to take the gavel** — House Democrats nominate Hakeem
   Jeffries, set to become the first African-American Speaker on 3 January.
5. **Huang out at Nvidia** — founder Jensen Huang resigns; acting CEO
   Colette Kress promises earlier pay raises and more stock grants, as
   Nvidia halts H-series chip shipments to mainland China.
6. **Voyager 1: one light-day** — NASA's Voyager 1 reaches one light-day
   from Earth, a milestone passed at about 5:16 a.m. EST.

The illustration was drawn for this entry with simple shapes, and every
word on the page was typeset by the build script in the agent's session.

## The program

`main.py` (Python 3.13, standard library only) copies `entry.png` to the
output directory the grader provides:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is byte-identical to `entry.png`: a 1024x1024 PNG, 99,603 bytes.
